# Trackademia 

Trackademia is a Notion-style workspace built around voice; you speak your notes, and it automatically transcribes them into clean, organized pages, blocks, and databases, so you never lose an idea to slow typing.

## Problem

Students struggle to manage their academic life because notes, tasks, deadlines, schedules, and files are scattered across multiple apps. They use one app for notes, another for calendars, another for to-do lists, and separate folders for school files. This fragmentation leads to:

- Forgotten deadlines and missed requirements
- Wasted time switching between different platforms
- Disorganized files and notes that are hard to find
- Increased stress and poor academic performance
- No single view of overall academic progress

### Existing Solutions: 

1.) Notion — All-in-one workspace but too complex and overwhelming for students with a steep learning curve
2.) Google Calendar — Scheduling and reminders but only for schedules, no note-taking or task management
3.) Google Docs/Keep — Note-taking but no task management or deadline tracking
4.) Trello/Asana — Task management but designed for teams and projects, not for students
5.) Evernote — Note-taking but limited task management and expensive
6.) Microsoft OneNote — Note-taking but has a clunky interface and limited organization features
7.) MyStudyLife — Student planner but no note-taking or file management

#### What Makes Trackademia Different?

1.) Student-first design — Built specifically for students, not adapted from general productivity tools
2.) All-in-one workspace — Notes, tasks, deadlines, schedules, and files in one platform
3.) Speech-to-text feature — Hands-free note-taking and task creation, perfect for lectures and quick idea capture
4.) Simple and intuitive— No steep learning curve, focused on what students actually need
5.) Subject-based organization — Separate workspaces for each subject for easy navigation
6.) Progress tracking — Monitor assignment and project progress from pending to completed

##### Feasibility Check

- Budget (₱50,000) — Feasible. Focus on core features, use open-source tools, and adopt agile development with MVP approach.
- Time (2-3 months) — Feasible. Build MVP with essential features (notes, tasks, deadlines, speech-to-text), launch beta, and iterate based on user feedback.
- Skills — Feasible. Use modern web technologies (React, Node.js, Firebase/MongoDB) with a small team of 4 members.
- Technology — Feasible. Speech-to-text can be integrated using free/affordable APIs like Web Speech API or Google Cloud Speech-to-Text.

###### Core Feature 
"Unified Workspace with Speech-to-Text"

The platform must allow students to:
- Create subject-based workspaces
- Add notes, tasks, and deadlines in one place
- Use speech-to-text to dictate notes and tasks hands-free

Why this feature survives: It is the heart of Trackademia. Without it, the app is just another productivity tool. With it, students can capture ideas instantly during lectures, create tasks without typing, and stay organized with minimal effort. This feature alone differentiates Trackademia from every other student app and delivers immediate value to users.
